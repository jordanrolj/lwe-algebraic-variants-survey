
# LWE and Algebraic Variants

A short survey written for my CSE 598 (Lattices in Cryptography) final project on Learning With Errors (LWE), Ring-LWE, Module-LWE, Polynomial-LWE, and Order-LWE.

The writeup focuses on worst-case hardness reductions, ideal lattices, algebraic structure in lattice-based cryptography, and applications to post-quantum cryptography and fully homomorphic encryption.

## References

Main references include Regev’s LWE paper, Lyubashevsky–Peikert–Regev on Ring-LWE, Peikert’s Ring-LWE instantiation notes, Algebraic LWE Revisited, and PRSD on decision Ring-LWE.
